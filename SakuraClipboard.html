Core Features

剪贴板，也需要整理感

围绕日常复制、找回、归档三件事设计，避免内容散落，也避免过度打扰。

⌘

文本与图片历史

自动记录文本和图片，点击任意条目即可重新复制回剪贴板。

⌕

快速搜索筛选

支持关键字、类型、时间范围、收藏状态和收藏夹筛选。

★

收藏夹管理

重要条目可加入收藏，并直接分配或修改收藏夹。

▣

长文本与图片预览

长文本可折叠展开，图片内容可预览，查找更直观。

◈

本地持久化

使用 SQLite 保存历史，支持更大容量和更快检索。

↻

安全清理

清空时仅删除未收藏内容，重要收藏会保留。

Workflow

从菜单栏开始

SakuraClipboard 保持轻量，不占据桌面，只在需要找回内容时出现。

01

打开菜单栏

从 macOS 菜单栏进入历史列表。

02

搜索或筛选

按文字、类型、时间或收藏夹快速缩小范围。

03

点击复制

点击条目即可复制回系统剪贴板。

04

收藏归档

把重要内容放进收藏夹，之后仍能保留。
