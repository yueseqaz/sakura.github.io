这是 macOS Gatekeeper 安全机制导致的，解决方法如下：

  1. 打开 终端 (Terminal)
  2. 输入以下命令并回车：
$ sudo xattr -rd com.apple.quarantine /Applications/SakuraWallpaper.app
  1. 输入你的 Mac 登录密码（输入时不会显示字符），按回车
  2. 重新打开 SakuraWallpaper 即可正常使用
💡 如果仍无法打开，请前往 系统设置 → 隐私与安全性 → 安全性，点击"仍要打开"。

请尝试以下排查步骤：

  1. 确认状态栏图标显示为绿色（表示壁纸正在运行）
  2. 检查是否在状态栏菜单中意外暂停了壁纸
  3. 尝试点击 Stop Wallpaper 后重新选择壁纸
  4. 如果是外接显示器，请在下拉框中确认选择了正确的屏幕
  5. 重启应用：退出后重新打开 SakuraWallpaper
💡 确保你的 macOS 版本 ≥ 12.0，较旧系统可能不兼容。

  2. 勾选底部的 "开机自启动" 复选框
  3. 设置会自动保存，下次开机时应用会自动运行并恢复上次的壁纸

你也可以在 系统设置 → 通用 → 登录项 中管理开机启动项。

  1. 在主窗口的屏幕选择下拉框中选择目标显示器
  2. 点击 Choose Wallpaper 为该屏幕设置壁纸
  3. 切换到另一个显示器，重复上述操作
  4. 如需所有屏幕使用同一壁纸，点击 "Apply to All" 按钮

每个屏幕的壁纸配置会独立保存，重启应用后自动恢复。

视频壁纸会占用一定的 GPU 和 CPU 资源。以下建议可以帮助降低影响：

  • 使用分辨率适中的视频（推荐 1080p），避免 4K 视频
  • 不使用时通过状态栏菜单暂停壁纸
  • 笔记本用户建议在接电源时使用动态壁纸
  • 图片壁纸对性能几乎没有影响

$ rm -rf ~/Library/Preferences/com.sakura.wallpaper.plist
